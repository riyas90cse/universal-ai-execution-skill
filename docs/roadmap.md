# Roadmap

This roadmap is directional. Issue scope remains the source of truth for actual work.

## v0.1.0: Skill Foundation

- Portable Universal AI Execution Skill router.
- Workflow Registry v1 with 46 workflows.
- Generated readable registry documentation.
- Core repository docs, license, security policy, and contribution guidance.

## v0.2.0: Registry Hardening

- Stronger registry validation.
- Clearer workflow ID stability rules.
- Improved generated documentation consistency.
- Additional checks for required workflow fields.

## v0.3.0: Adapters and Examples

- Codex adapter.
- Claude Code project instruction adapter.
- Generic LLM invocation prompt.
- Cursor rule format.
- GitHub Copilot instruction format.
- Symphony-style orchestration guidance.
- Practical examples for common workflow selections.

## v0.4.0: Tests and Validation

- Structure tests.
- Workflow registry integrity checks.
- Generated registry checks.
- Standalone validation script.
- Pull request CI for quality gates.

## v1.0.0: Stable Public Release

- Stable public workflow ID policy.
- Complete release checklist.
- Current README, changelog, security policy, contribution guide, and versioning policy.
- Passing tests and structure validation.

## Future Ideas

- CLI.
- Registry linter.
- Workflow scoring.
- More adapters.
- Real-world case studies.

Future ideas are not committed scope until tracked by issues.
