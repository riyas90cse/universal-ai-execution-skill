# GTM Strategy Example

## User Request

"We are launching a developer observability tool for seed-stage SaaS teams. Build a go-to-market strategy with ICP, channels, messaging, and validation loops."

## Detected Task Type

Go-to-market strategy and launch motion planning.

## Selected Workflow

`gtm-strategy`

## Why This Workflow Was Selected

The request asks for customer targeting, channels, messaging, distribution, and launch validation.

## Expected Output Structure

- Task intake card with market, audience, and constraints.
- ICP and pain summary.
- Channel audit and distribution plan.
- Messaging plan with proof points.
- Risks and assumptions.
- Messaging validation plan.
- Action plan with validation loops.

## Good Prompt

"Create a GTM strategy for a developer observability tool targeting seed-stage SaaS teams. Define a narrow ICP, connect channels to buyer behavior, draft messaging, and include validation experiments."

## Bad Prompt To Avoid

"Make a launch plan that targets all engineering teams and lists every possible marketing channel."
