# Test Strategy Example

## User Request

"Create a testing strategy for the new checkout flow. We need to know current coverage, high-risk paths, and what to add before release."

## Detected Task Type

Risk-based testing strategy for a product feature.

## Selected Workflow

`testing-strategy`

## Why This Workflow Was Selected

The request asks to design and evaluate the testing approach for a feature and release risk.

## Expected Output Structure

- Task intake card with feature scope and release boundary.
- Current test inventory.
- Risk audit for critical user paths and failure modes.
- Test pyramid design.
- Coverage gap analysis.
- Target testing strategy.
- Prioritized coverage gap action plan.
- Validation criteria for release readiness.

## Good Prompt

"Design a test strategy for checkout. Inventory existing tests, rank payment, tax, discount, retry, and failure paths by risk, and propose the smallest coverage plan before release."

## Bad Prompt To Avoid

"Add enough tests to get good coverage."
