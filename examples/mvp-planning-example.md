# MVP Planning Example

## User Request

"We want to build a scheduling assistant for small clinics. Help define the smallest MVP that tests whether clinics will use and pay for it."

## Detected Task Type

Product MVP scope and validation planning.

## Selected Workflow

`mvp-planning`

## Why This Workflow Was Selected

The request asks to narrow a product idea into the smallest useful version that tests the core risk before build expansion.

## Expected Output Structure

- Task intake card with customer, problem, assumptions, and constraints.
- MVP goal and non-goals.
- Assumption audit with riskiest assumptions.
- Scope cut with included and excluded features.
- Prioritized feature set tied to learning goals.
- Validation plan with measurable learning criteria.
- Next actions.

## Good Prompt

"Define an MVP for a clinic scheduling assistant. Identify the riskiest assumptions, cut non-essential features, and propose validation steps before building beyond the first workflow."

## Bad Prompt To Avoid

"Design the complete product with billing, messaging, analytics, referrals, and admin roles."
